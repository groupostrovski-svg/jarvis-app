Privacy Policy

Last updated: October 16, 2026

1. A personal application

Jarvis is a personal voice assistant. It is used only by its owner, on the owner's own PC. It has no other users and is not offered to the public.

2. Google data it accesses

With the owner's permission, Jarvis accesses the owner's Gmail and Google Calendar. This access is used only to carry out the owner's own voice requests — for example, to tell the owner what is on the calendar, add an event the owner asked for, or answer a question about the owner's email.

3. How data is processed

  • Data is processed on the owner's PC.
  • To handle a request, the relevant data and the owner's request are sent to the Anthropic Claude API for processing.
  • Jarvis does not use Google data for advertising, profiling or any purpose other than the owner's request.

4. Sharing

Data is not sold and is not shared with or transferred to third parties, other than sending a request to the Anthropic Claude API for processing as described above.

5. Revoking access

The owner can revoke Jarvis's access to the Google account at any time at https://myaccount.google.com/permissions.
